# Landing Page PT Bursa Efek Indonesia (BEI)

## Menjalankan
1. Ekstrak folder `bei-landing-page`.
2. Buka folder proyek di VS Code dan jalankan `index.html` dengan ekstensi Live Server. Menyajikan folder melalui server lokal membantu browser menemukan gambar dan memutar video lokal dengan benar.
3. Pastikan koneksi internet tersedia untuk Google Fonts dan Material Symbols.

## Struktur
- `index.html` — struktur dan konten halaman.
- `style.css` — seluruh desain desktop, tablet, dan mobile.
- `script.js` — menu mobile, pencarian, tab visi/misi, grafik ilustrasi, modal video, galeri lightbox, dan tombol kembali ke atas.

## Catatan fungsional
- Halaman menggunakan satu HTML responsif untuk desktop dan mobile.
- Data IHSG pada halaman adalah data ilustrasi, bukan feed real-time.
- Video profil menggunakan file lokal `1126_2000s.mp4` di folder yang sama dengan `index.html`.
- Tombol EN saat ini memberi pemberitahuan bahwa terjemahan belum disediakan.
- Galeri menggunakan semua 12 foto lokal: `BEI-toro-1.jpeg`, `bingkai.jpeg`, `bingkai_2.jpeg` hingga `bingkai_9.jpeg`, `hall.jpeg`, dan `hall_2.jpeg`. Simpan foto-foto tersebut di folder yang sama dengan `index.html`.
